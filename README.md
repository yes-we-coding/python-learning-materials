## ⚠ 关于文件大小

所有压缩包通过 **Git LFS** 存储,克隆时需执行:
```bash
git lfs install
git clone https://github.com/yes-we-coding/python-learning-materials.git
```
直接 `git clone` 不带 LFS 会得到 LFS 指针文件,需额外 `git lfs pull` 拉取真实内容。
